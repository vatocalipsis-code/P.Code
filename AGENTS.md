# P.Code / Picot — инструкция для интеграции с U.Cash

P.Code — самостоятельный движок интерфейса. При сборке, изменении или публикации P.Code как зависимости U.Cash обязательно читать [политику релизов U.Cash от 14.10.2026](/home/tot/projects/ucash-monobank-20261008/docs/canon/RELEASE-POLICY.md). Точный Picot Git SHA входит в manifest единого immutable artifact; после личной приёмки Тотом в DevPublic этот же artifact без пересборки применяется ко всей клиентской группе. Отдельное изменение Picot после одобрения требует нового полного цикла. Эта инструкция не изменяет выпуск самостоятельного P.Code и не даёт разрешения на DEPLOY U.Cash.
